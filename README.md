# İlan Pusulası

CV yetkinliklerini iş ilanının beklentileriyle karşılaştıran, eşleşmeleri ve gelişim alanlarını gösteren tarayıcı tabanlı analiz aracı.

## Özellikler

- CV ve iş ilanı metninden yetkinlik çıkarımı
- Dinamik eşleşme puanı
- Eşleşen ve eksik beceri listeleri
- Başvuruya özel gelişim önerileri
- Sonuç özetini panoya kopyalama
- Metinleri sunucuya göndermeden yerel analiz
- Mobil ve masaüstü uyumlu tasarım

## Çalıştırma

```bash
npm install
npm run dev
```

## Teknolojiler

React, TypeScript, Vinext, Local Storage ve CSS.
